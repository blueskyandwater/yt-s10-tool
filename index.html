YouTube S10 analytics

YouTube S10 analytics は、開発者本人が運営する YouTube チャンネルの数字（視聴回数・視聴時間・サムネイルの表示回数とクリック率など）を、YouTube Analytics API と YouTube Reporting API から読み取り、動画ごとの振り返りに使うための個人用の道具です。

  • 利用者は開発者本人だけです。一般には提供していません。
  • 要求する権限は読み取りだけです（yt-analytics.readonly・youtube.readonly）。動画・チャンネルの変更、投稿、削除はしません。

プライバシーポリシー

YouTube S10 analytics is a personal, read-only tool that the developer uses to review the analytics of their own YouTube channels. It is not offered to the public. See the Privacy Policy.
