プライバシーポリシー

対象：YouTube S10 analytics（以下「本ツール」）。制定日：2026年11月10日。

1. 利用者

本ツールは、開発者本人が自分の YouTube チャンネルの数字を読むためだけに使う個人用の道具です。第三者への提供はしていません。

2. 取得する情報

Google の OAuth で許可されたアカウントについて、次の読み取り専用の範囲だけを使います。

  • https://www.googleapis.com/auth/yt-analytics.readonly：チャンネルと動画の分析データ（視聴回数、視聴時間、平均視聴率、流入元、サムネイルの表示回数とクリック率など）
  • https://www.googleapis.com/auth/youtube.readonly：チャンネルの ID、動画の一覧・公開日時・長さ

視聴者個人を特定する情報は取得しません（YouTube の分析データは集計値です）。

3. 使い方

取得したデータは、開発者本人が動画ごとの振り返り（公開後2日・7日・28日の観測など）に使うだけです。広告、販売、第三者への共有には使いません。

4. 保存

データは開発者本人の端末とその非公開のバックアップに保存します。認証のトークンは端末の資格情報ストア（Windows の資格情報マネージャーなど）に保存し、ほかの場所には置きません。

5. Google API のデータの扱い

本ツールによる Google API から受け取った情報の使用と他のアプリへの転送は、限定的使用の要件を含め、Google API サービスのユーザーデータに関するポリシーに従います。

6. 許可の取り消し

許可は Google アカウントの「サードパーティのアクセス」からいつでも取り消せます。取り消した後、本ツールは新しいデータを取得できません。

7. 変更

内容を変えるときは、このページを更新します。
